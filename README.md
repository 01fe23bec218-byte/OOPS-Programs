### How to Compile and Run

To compile and execute any program using GCC/Clang:

```bash
# Navigate to the class directory
cd Programs/Class-01

# Compile
g++ program1.cpp -o program1

# Run (Windows)
.\program1.exe

# Run (Linux/macOS)
./program1
```
